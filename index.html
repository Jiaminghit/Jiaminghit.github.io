01动态标注 2D 质检75.0% / 84.5% Precision / Recall 代理指标+

面向人工质检前的异常预筛，将相机 2D 检测算法 接入 LiDAR 3D 动态标注链路，完成 3D 框多相机投影、Ego ROI 过滤及 2D–3D 实例关联；基于归一化重叠率与匈牙利算法实现全局匹配，并构建疑似误检、遮挡、视野外三类异常分流机制，设计3D准确率和2D召回率任务级质量指标。在8个测试生产数据CLIPs（3200帧） 中完成 6.46 万组实例匹配，主要动态类别（Car、Truck、Bicycle、Pedestrian）Precision、Recall代理指标分别达到75.0%和84.5%，自动标记 1.21 万个疑似误检 并补充1.18 万个疑似漏检线索，辅助人工聚焦异常结果；

02标注后处理链路99.86% 候选 Feature 处理覆盖率+
